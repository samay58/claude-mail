## Key Technical Decisions

### 1. Deterministic Gates First
- RFC-compliant detection provides high-confidence signals
- No ML required for clear patterns (newsletters, auto-replies)
- Reduces false positives in critical categories

### 2. Confidence Scoring
- Each gate returns confidence (0.0-1.0)
- Multiple signals combine for higher confidence
- Thresholds tuned per gate type

### 3. Feature Engineering
- 25+ features cover all aspects of email importance
- Balanced between deterministic and predictive features
- Designed for both accuracy and explainability

### 4. Modular Architecture
- Each gate is independent and testable
- FeatureExtractor orchestrates without tight coupling
- Easy to add new gates or modify existing ones
